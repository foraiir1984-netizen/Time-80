# دارایی‌های مستقل M-10 — v1

`today-mountain-v1.png` خروجی اصلی ابزار OpenAI image_gen است؛ تصویر مستقل کوهستان و جنگل با نور گرم، بدون متن، UI یا قاب گوشی. ورودی تصویری ثالث استفاده نشد و موکاپ برش داده نشد. فایل source.json منشأ، شناسه ساخت، ابعاد و SHA-256 را نگه می‌دارد. استفاده در محصول طبق درخواست صاحب محصول مجاز است؛ حقوق خروجی میان کاربر و OpenAI مطابق [شرایط استفاده OpenAI](https://openai.com/policies/terms-of-use/) و در حدود قانون متعلق به کاربر است. این توضیح ادعای انحصار تصویر یا مجوز ساختگی stock/CC0 نیست.

روش تولید: prompt متنی مستقل «کوه هرمی برفی، نور گرم روی دامنه، جنگل سبز و مه دره، کرم و سبز طبیعی؛ بدون نوشته، آیکون، watermark یا UI». PNG اصلی بدون تغییر بایت کپی شد؛ Image در runtime از resizeMode=cover استفاده می‌کند. این دارایی موقت نیست؛ کیفیت crop و رنگ روی Android هنوز Not run است. نسخه مدل در پاسخ ابزار اعلام نشده است (Not Available).

شمع در `src/components/DayPassage.tsx` یک تصویر برداری اولیهٔ مستقل با هندسه قابل‌مقیاس است؛ بخش تصویرسازی DayCandle برای استفاده و بازتوزیع پروژه با CC0-1.0 ارائه می‌شود: https://creativecommons.org/publicdomain/zero/1.0/. renderer موجود react-native-svg آن را مستقیم از هندسه می‌سازد. قاب/پس‌زمینهٔ تصویری ندارد. ارتفاع wax از همان progress مصرفی Donut می‌آید و پایان روز به ته‌ماندهٔ کوتاه بدون شعله می‌رسد. این بازنمایی ساده عمق سه‌بعدی موکاپ را ادعا نمی‌کند؛ native QA باز است.

Vazirmatn v33.003 از assets/fonts/vazirmatn و مجوز OFL-1.1 موجود بازاستفاده شد. آیکون‌های فعالیت همان registry و PNGهای time80-a-v1 هستند؛ هیچ identity یا مقدار legacy تغییر نکرد.
