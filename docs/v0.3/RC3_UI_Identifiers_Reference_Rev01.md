# مرجع کامل شناسه‌های قابل‌دیدن RC3 — Rev01

تاریخ: 2026-10-12، Asia/Tehran. شناسه سند: RC3-ID-REF-01. نسخه: Rev01.
همراه: الحاقیه ۶-الف؛ ادامه پرامپت ۶ / RC3-ID-01. این فایل تازه است؛ جایگزین فایل وضعیت نیست و نیاز به ارسال دوباره فایل‌های قبلی ندارد.

## اختیار، منشأ و وضعیت

این سند جدول‌های کامل ارسال‌شده توسط صاحب محصول در همین دفتر و معیارهای AC-ID-01…10 را یک‌جا منتقل می‌کند؛ تخصیص تازه یا حدسی نیست. محل‌ها و شماره‌خط‌ها از inventory سورس RC2 مورخ 2026-10-11 نقل شده‌اند، نه از بررسی دوباره تمام فایل‌های HEAD جاری. هنگام اجرا محل جاری را پیدا کن؛ جابه‌جایی فایل/خط کد را عوض نمی‌کند.

مبنای جاری FIX02: `ffa7bfc1dcb18c747611d585553bed4d4e4d5359`.
RC2 مرجع inventory: `8e1cef5c0bdf0d471a0ed6cfbd02872b127f7634`.
Checkpoint دریافت‌شده 2026-10-12: شاخه محلی `rc3-id01-ui-identifiers`؛ HEAD همان FIX02؛ تغییرات uncommitted شامل زیرساخت registry/badge/guide و X69…X72/X75. طبق گزارش Codex typecheck Pass، UTC92/92 و تست‌های مرتبط تهران62/62؛ شواهد این مرحله هنوز در دفتر بررسی نشده‌اند. تصاویر/اندازه‌گیری گوشی Not run. مانع انتقال جدول با این سند رفع می‌شود. تغییرات فعلی حفظ شوند؛ task از نو شروع نشود.

دامنه ادامه همان پرامپت۶ است: UI موجود غیرمرتبط با ICATUS کدگذاری شود؛ پنهان‌سازی ICATUS و چهار بازطراحی مراحل بعدند. برای قابلیت‌های هنوز موجود ولی در انتظار پنهان‌سازی، «pending hide» صریح ثبت شود. رزرو شناسه اثبات حذف UI نیست.
