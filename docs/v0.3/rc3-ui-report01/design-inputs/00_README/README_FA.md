# Time80 — Product UI Handoff

**تاریخ بسته:** 2026-10-06  
**مقصد:** دفتر محصول Time80  
**نوع تحویل:** مجموعه تصمیم‌های UI/UX تأییدشده + استانداردهای بصری + موکاپ‌های مرجع  
**نسخه محصول:** تعیین توسط دفتر محصول (این بسته به‌تنهایی شماره نسخه Release را تعیین نمی‌کند)

## هدف بسته
این بسته یک مرجع self-contained برای تصمیم‌های طراحی تأییدشده در صفحات «گزارش»، «تنظیمات یادآوری» و «امروز» است. برای فهم تصمیم‌ها نیازی به مراجعه به تاریخچه Chat نیست.

## موکاپ‌های تأییدشده
- **M-01** — انتخاب بازه زمانی گزارش
- **M-02** — تنظیمات یادآوری مینیمال
- **M-04** — خلاصه فعالیت‌ها + نمودار Donut
- **M-10** — صفحه امروز / Final Visual Reference

## ساختار بسته
- `01_Product_Decisions/` — تصمیم‌ها، هدف UX و موارد باز
- `02_Design_System/` — Typography و Visual normalization
- `03_Approved_Mockups/` — تصاویر مرجع تأییدشده

## ترتیب مرجع در صورت تعارض
1. تصمیم‌های صریح Product/UX در `01_Product_Decisions`
2. `Time80_Typography_Normalization_v1.0_FA.md`
3. `Time80_Visual_System_Normalization_v1.0_FA.md`
4. موکاپ‌های تصویری
5. UI قدیمی / اسکرین‌شات‌های Legacy

**قاعده مهم:** موکاپ تصویرِ قصد طراحی است، نه منبع اندازه‌گیری پیکسلی. اندازه فونت، spacing، radius و icon size باید از اسناد Design System گرفته شوند.

## وضعیت تأیید
چهار موکاپ M-01، M-02، M-04 و M-10 از نظر جهت طراحی تأیید شده‌اند. بازتولید تصویری برای M-01/M-02/M-04 لازم نیست؛ Implementation باید آن‌ها را با استانداردهای این بسته normalize کند. M-10 یک Final Visual Reference جدید دارد.

## مواردی که این بسته تعیین نمی‌کند
- شماره Version/Release مقصد
- منطق Product برای تشخیص «فعالیت مفید/غیرمفید»
- Trigger نهایی حالت احساسی مثبت/منفی
- مشخصات نهایی صدا و Haptic
- Hex نهایی توکن سبز/نارنجی (جهت رنگی تأیید شده، tokenization نهایی هنوز باید در UX/Implementation تثبیت شود)
